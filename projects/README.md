# Project notes

A project note is the durable home for one effort: names, decisions, and gotchas that will still matter after the current task ends. Link it from the index in `MEMORY.md`.

- One subject per file. A payments note does not also store website design.
- One fact per line, with `source` and `added` when you have them.
- Current status does not live here. It lives in `progress/`, and it is rewritten when it changes. When a progress bullet turns into a lasting lesson, move that lesson here and drop the status line.
- Link a sibling note instead of repeating it: `see [[projects/example-payments]]`.

[example-payments.md](example-payments.md) is a fictional sample. Delete it in a real repo, or replace it with a real project.
